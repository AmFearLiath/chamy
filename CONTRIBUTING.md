# Contributing

Danke für dein Interesse an Chamy. Der Projektinhaber hat entschieden, dass keine externen Beiträge (Pull Requests) angenommen werden.

Wenn du Support brauchst oder Fehler melden möchtest, öffne bitte ein Issue (siehe Issue‑Vorlagen) oder nimm direkt Kontakt mit dem Eigentümer auf.

Für interne Maintainer:
- Folge den Coding‑Standards (PSR‑12)
- Schreibe Unit‑ und Integrationstests für neue Features
