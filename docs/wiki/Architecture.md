# Architektur & Komponenten

Kurzüberblick über Kernel, Module, Manager‑Schicht und Datenprovider.

- `core/` — Framework‑Kern, Bootstrap, Kernel, Managers
- `modules/` — Feature‑Module (z. B. legal_manager)
- `themes/` — Frontend & Admin Twig Templates
- `storage/` — Cache, logs, secrets (nicht im Repo)

Siehe `docs/` für detaillierte Diagramme.
